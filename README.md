# 🚀 Mohammad Baniyounis | Full-Stack Web Developer Portfolio

A premium, interactive, and fully responsive personal portfolio designed to showcase software engineering projects, modern UI/UX design paradigms, and programming skills. 

✨ **Live Demo:** ( https://m0haammad.github.io/Portfolio/) 

---

## 🎨 Design & Key Features

* **Glassmorphic UI**: Semi-transparent, blur-backed navigation header and footer that seamlessly blend with the dynamic background.
* **Ambient Neon Background**: Glowing, drift-animated ambient light blobs overlaid with a technical coordinates grid.
* **Floating Code Particles**: Live dynamic canvas injecting floating and rotating programming symbols (`async/await`, `npm run`, `React`, etc.) floating drift-wise in the viewport space.
* **Mockup Code Terminal**: A modern console simulation featuring a custom typewriter script that types out a syntactically colored JavaScript object of my professional profile.
* **Responsive 3D Project Cards**: A grid of fully responsive project articles showcasing clean typography, technical stacks, hover zoom states, and interactive links to GitHub code and live deployments.

---

## 🛠️ Technology Stack

* **Core Structure:** HTML5 (Semantic elements, SEO-optimized structure)
* **Aesthetics & Layout:** Vanilla CSS3 (Custom properties/variables, Flexbox, CSS Grid, custom keyframe animations)
* **Interactions:** Vanilla JavaScript ES6+ (Typewriter animation engine, floating symbols loop, dynamic mobile menu trigger)
* **Assets:** FontAwesome v6 (Icons), Google Fonts (Inter, Roboto Mono)

## 🚀 Running Locally

1. Clone this repository:
   ```bash
   git clone https://github.com/M0haAmmad/Portfolio.git
   ```
2. Open the directory:
   ```bash
   cd Portfolio
   ```
3. Open `index.html` directly in your browser, or run a local server:
   ```bash
   # If you have Node/npm installed
   npx local-server
   
   # Or using Python
   python -m http.server 8000
   ```
